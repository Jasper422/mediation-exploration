# 多中介与多结果探索分析

**mediation-exploration** 是一个面向实验与问卷研究的 AI 分析技能，用来探索多个中介变量与多个结果变量之间的候选机制。

它按“读取数据 → 检查质量 → 确认计分 → 确认模型 → 批量估计 → 比较稳定性 → 审查机制 → 制作图表 → 复核交付”的流程工作。完成分析后，同时提供**多个候选按优先级排列的总结性报告**和**详细分析过程报告**。

本仓库提供技能说明、四份分析参考文件和一个候选结构生成脚本。支持 skills 的 AI 工具读取这些规则后，结合可用的文件工具及统计计算环境开展分析；候选生成脚本本身只负责列出结构草案，不拟合中介模型。

## 适合解决什么问题

- 有多个中介和多个 DV，希望系统比较单中介、双中介并行模型。
- 希望保留多个值得验证的候选，并判断哪些优先、哪些属于次级探索或补充对照。
- 想了解结果是否依赖计分方法、样本排除、协变量或估计方式。
- 除了数值结果，还希望结合 thought listing 等开放式回答寻找机制线索和反例。
- 需要给导师或团队一份便于讨论的总结，同时保留完整、可复核的分析过程。

例如，有四个中介和三个 DV，若研究问题支持完整比较，可形成每个 DV 的四个单中介和六个双中介并行结构，共 30 个候选模型、48 条特定间接路径。技能也能适配其他数量，不将这个示例固定为所有项目的分析范围。

## 三项核心约定

### 先读材料 再在关键节点确认

AI 先读取操作者提供的文件，整理自己的理解。在**第三步计分与测量**、**第四步候选模型方案**分别展示具体方案并请求确认。两次确认独立进行，不以一次“是”代替全部批准。

### 报告多个候选 并解释优先级

总结报告分别展示每个 DV 的单中介与双中介候选，结合理论、效应大小、区间、多重比较、稳定性及模型新增信息给出优先级。完整结果继续保留未获支持的模型，不只交付一个排名第一的组合。

### 同时交付总结和详细过程

总结报告回答“可以选哪些、先看哪些、为什么”；详细报告说明“如何从原始字段得到这些结果、哪些选择影响结论、还有哪些证据缺口”。两份报告使用一致的模型编号、变量含义和统计结果。

## 九步分析流程

| 步骤 | 主要工作 | 主要产出 |
| --- | --- | --- |
| **1 读取与整理数据** | 读取工作表、分组字段、题干、量表题项、DV 与文字回答；识别类别标签、单位及来源列 | 数据字典、字段对应表、编码映射 |
| **2 检查数据质量** | 检查缺失、同意参与与完成状态、重复记录线索、作答时长、异常值影响、分配题总额及采样单位 | 数据质量报告、处理草案、保留与排除记录 |
| **3 检查计分与测量** | 提出题项归属、正反向、量尺、合成及缺失题规则；先确认理解，再计算正式构念得分和测量诊断 | **确认点一**、计分规则、中介得分、测量问题清单 |
| **4 建立候选组合** | 根据理论和测量结果提出单中介、双中介并行结构；说明协变量、样本规则、区间、多重比较及敏感性方案 | **确认点二**、候选模型清单、纳入与排除理由 |
| **5 批量运行与诊断** | 按已确认方案估计模型；报告总效应、直接效应、总间接及特定间接效应；检查共线性、残差、影响个案与收敛情况 | 完整模型结果、特定路径表、诊断记录 |
| **6 比较结果稳定性** | 比较有依据的替代计分、样本规则、协变量和估计规格；识别方向、区间与候选排名的变化 | 稳定性表、敏感性说明、选择影响记录 |
| **7 审查候选机制** | 检查构念重叠、竞争解释、时间顺序、混杂及双模型中新增路径的贡献 | 候选机制证据卡、证据缺口、下一步验证建议 |
| **8 制作正式图表** | 展示原始分布、各 DV 的效应、候选模型间接效应及合理规格下的变化 | 效应区间图、组合比较图、稳定性图 |
| **9 复核分析交付** | 核对计分、样本、候选数、计算、图表及文字；检查两份报告的结论与优先级一致 | 总结性报告、详细过程报告、完整结果与复核记录 |

### 可穿插开展的文字回答分析

对 thought listing、开放式问卷回答等材料，可另外建立内容编码规则，保留原文依据、反例、重复文本情况和人工复核状态。

文字分析可以提出新的候选线索，也可以揭示与量化解释不一致的回答。AI 初始编码会明确标注为待复核；未经独立人工编码，不声称已有编码一致性或 κ 系数验证。文字线索也不会被直接当作已经验证的中介。

## 两个确认点如何工作

### 确认点一 第三步的计分与测量理解

AI 读取材料后，展示“计分与测量理解”，包括：

- 分组来源、类别编码、参照组及对比方向。
- 每个中介的构念名称、来源题项、分值范围和正反向。
- 均值或总分、反向公式、最低有效题数和缺失规则。
- 每个 DV 的来源、单位、量尺类型和分配限制。
- 采样单位、施测顺序及尚未从材料确认的事项。

随后请求操作者回答：

```text
1. 是
2. 否，并补充
3. 部分同意，并补充
```

确认前可检查原始值与缺失、整理字段和计分草案；通过后才计算正式构念得分，检查内部一致性与构念重叠。不会先跑完中介分析再补问计分是否正确。

### 确认点二 第四步的候选与分析方案

计分已确认、初步测量检查完成后，AI 展示“候选与分析方案”，包括：

- 每个 DV 拟比较的单中介和双中介组合，以及纳入理由。
- 明确不纳入的结构；如考虑链式中介，需要理论与时序依据。
- 主分析样本、缺失处理、处理前协变量和估计方法。
- 区间方法、重抽样单位、次数、种子与多重比较范围。
- 拟开展的稳健性规格，以及候选优先级的比较依据。

此处再次使用相同三个选项，确认后才批量拟合候选模型。

选择“否”或“部分同意”时，AI 先根据补充修订方案，再展示修订版请求确认。未答复或超时保持待确认状态。同一数据、同版方案已有对话中的明确确认时，可沿用该确认。

详细规则见 [确认与分析状态](references/confirmation.md)。

## 第一类输出 总结性报告

总结报告面向研究讨论，按每个 DV 分别呈现单中介、双中介的多个候选，并使用以下层级：

| 层级 | 含义 |
| --- | --- |
| **优先报告** | 理论和统计证据较充分，合理规格下较稳定；双模型还需检查新增路径的信息 |
| **次级探索** | 有一定证据，但多重校正、稳定性、理论或新增路径支持较弱 |
| **补充对照** | 用于竞争解释或敏感性比较；也可能总间接效应有信号，但新增中介自身缺少支持 |
| **未获支持** | 当前数据没有提供清楚支持，仍保留效应、区间和局限 |

单中介总结表通常包括：**DV、层级与组内顺序、中介名称、原单位间接效应与 95% 区间、校正后的证据、样本量、稳定性和保留理由**。

双中介总结表通常包括：**DV、层级与组内顺序、组合及结构类型、总间接效应与 95% 区间、每条特定路径的证据、相对单中介的新增信息，以及稳定性**。

报告会特别区分：一个双中介组合的总间接效应得到支持，是否同时意味着两个中介分别有贡献。若结果主要由其中一个中介带动，会直接说明。

“多个候选”不意味着凑出多个显著结果。充分支持的候选只有一个时，其余模型仍按次级探索、补充对照或未获支持展示；全部缺少支持时，也会如实报告。

## 第二类输出 详细分析过程报告

详细报告按九步流程组织，并单列文字回答分支，保留：

- 文件版本、来源字段、变量映射与未知编码。
- 数据质量检查、计分规则、样本保留/排除及其影响。
- 两个确认点展示过的方案、操作者答复和修订记录。
- 所有已尝试的候选结构、纳入理由、模型方程和计算设置。
- 全部模型与特定路径的效应、区间、多重比较、诊断和失败记录。
- 各稳健性规格的结果、估计目标变化、个案影响与排名变化。
- 理论、测量、时序、混杂、竞争机制及文字反例的审查。
- 图表、复核结果、尚未解决的问题和后续验证建议。

未指定报告格式时，可分别生成 `summary_report.md` 与 `analysis_process.md`。需要 Word、HTML、PDF、工作簿或科研图时，由当前环境具备的对应能力完成生成和验证。完整模型表及可复现脚本作为配套文件保留。

具体列结构和交付检查见 [两种报告的交付约定](references/reporting.md)。

## 开始前准备哪些材料

提供现有材料即可，AI 会先读取并整理理解；无法从材料确定的关键问题，在确认节点提出。

| 材料 | 作用 |
| --- | --- |
| Excel、CSV 等数据文件 | 提供原始记录；具体格式取决于当前读取工具的支持范围 |
| 问卷、题项说明或编码表 | 核对构念归属、反向题、量尺、DV 含义与类别标签 |
| 简短研究背景与实验情境 | 判断哪些组合有理论依据，避免只按显著性选择 |
| 实验设计说明 | 确认随机化、测量顺序、重复测量/聚类及协变量身份 |
| 开放式回答及已有编码手册 | 开展文字分析；有人工编码时可进一步安排复核 |

变量暂时不知道叫什么也可以先提供文件。缺少的设计依据会标记为未知，不用猜测填满分析表。

## 安装与调用

### 通过 Codex 的 skill-installer 安装

向具备 `skill-installer` 的 Codex 提出：

```text
请使用 $skill-installer 安装这个 GitHub 仓库根目录中的技能：
https://github.com/Jasper422/mediation-exploration

技能名称是 mediation-exploration，请保留它的 references、scripts 和 agents 目录。
```

如果技能放在一个较大仓库的子目录中，提供该子目录链接。安装需要相应的网络与仓库访问权限；完成后可在后续轮次调用。

### 调用示例

```text
使用 $mediation-exploration 分析我提供的数据。

请先读取数据、问卷和实验说明。
在第三步确认计分与测量理解，在第四步确认候选与分析方案。
两次确认均使用：1. 是 2. 否，并补充 3. 部分同意，并补充。

完成后同时提供：
一份按每个 DV 列出多个单中介、双中介候选及优先级的总结报告；
一份记录完整分析过程的详细报告。
```

也可以指定重点，例如“优先关注准备投入，保险意愿作为次级结果”，或“仅讨论有理论依据的组合”。这些选择会进入待确认方案。

## 如何配合已有 skills

本技能负责整体流程、两个确认点和报告约定。环境中有以下专业 skills 时，可以结合其能力完成对应步骤；它们不作为安装本技能的前置依赖。

| 能力或 skill | 在流程中的作用 |
| --- | --- |
| Spreadsheets | 读取与整理工作簿、建立字段映射、交付结果表格 |
| exploratory-data-analysis | 对支持的本地格式开展缺失、异常与分布检查 |
| 本技能的计分与测量规则 | 补齐第三步的题项方向、合成规则与测量检查 |
| 本技能的候选模型规则 | 补齐第四步的候选清单、纳入理由及确认机制 |
| statistical-analysis 与 statsmodels | 选择估计方案、批量运行、区间推断与诊断 |
| 本技能的稳定性规则 | 补齐第六步的合理规格比较与选择敏感性说明 |
| scientific-critical-thinking | 审查机制证据、竞争解释及因果推断条件 |
| qualitative-coding | 建立文字编码规则、保留原文依据并安排复核 |
| nature-figure | 制作和检查正式科研图表 |
| validate-data | 复核数据、方法、计算及结论是否一致 |

技能文件用于指导 AI 的工作；实际数值计算需要可用的 Python 或 R 等统计环境。已有专业 skills 不等于其软件依赖已经安装，执行时仍需检查环境。缺少某项能力时说明实际完成范围，不用虚构结果补齐流程。

## 候选清单辅助脚本

`scripts/generate_candidates.py` 使用 Python 标准库，生成单中介和双中介并行结构的 CSV 草案，不读取研究数据、不拟合模型，也不代表操作者已确认方案。

在仓库根目录运行：

```bash
python scripts/generate_candidates.py --mediators M1 M2 M3 M4 --outcomes DV1 DV2 DV3 --out candidates_draft.csv
```

该示例生成 30 个模型草案、48 条特定路径。可限定候选范围：

```bash
python scripts/generate_candidates.py --mediators M1 M2 M3 M4 --outcomes DV1 DV2 --single M1 M2 M3 --pairs M1+M2 M1+M3 M2+M3 --out selected_scope_draft.csv
```

使用内部别名如 `M1`、`DV1`，在数据字典中保留与原始中文题项/列名的对应。`M1+M2` 与 `M2+M1` 表示同一个并行结构，不代表相反的链式顺序。脚本会拒绝重复或不合法的结构，并拒绝覆盖已有输出文件。

纳入理由仍需结合研究背景补充，并在第四步确认。更多参数：

```bash
python scripts/generate_candidates.py --help
```

## 分析与解释边界

- **探索性选择需要后续验证。** 样本内优先级、拟合优度或重抽样选择频率，不等于机制为真或独立复现的概率。
- **区间与多重比较要说清楚。** 报告区分逐项区间、多重校正后的检验和模型选择后的不确定性，不把不同推断程序混写。
- **因果解释依赖设计。** 随机处理不自动消除中介与结果之间的混杂；时序、测量反应和竞争解释需要单独审查。
- **结果类型决定估计方案。** 二元/序数 DV、重复测量、聚类、多组处理和交互情形，需适配方法及重抽样单位。
- **数据处理保留依据。** 不为了显著性删题、删样本或选择计分；主分析与敏感性版本及其理由分别记录。
- **文字编码保留复核状态。** 初始主题是机制线索，不直接升级为已验证中介。
- **示例数据按示例解释。** 文件若含 simulated 等标记，核实并披露来源属性，不将其作为真实人群证据。

## 当前验证情况

技能的结构格式、UTF-8 编码、展示元数据及内部参考链接已检查；候选清单脚本通过了完整组合数量、限定候选范围、单中介边界、非法结构拒绝与已有文件保护等五项测试。

这些检查针对技能包和辅助脚本，不等于已对任意研究设计完成端到端统计验证。每次实际分析仍按上述确认、诊断和复核流程执行。
