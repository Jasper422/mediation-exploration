# 模型与稳定性

## 范围先于估计

第四步先解释研究问题、可识别的处理对比、结果及候选机制，选择有理由的结构再提交确认。使用已确认的计分与测量诊断，不预先拟合所有组合后只提交显著模型。

用户确实要求完整组合搜索时，P 个中介、Q 个 DV 的全体单/双并行模型数为 `Q × [P + P(P-1)/2]`；特定路径数为 `Q × [P + P(P-1)]`。4 个中介、3 个 DV 时是 30 个模型、48 条特定路径；基准 X-only 不计入该 30 个。数字只用于核对，不规定任何新数据必须有这些数目。

可用脚本生成未估计的草案：

```text
python scripts/generate_candidates.py --mediators M1 M2 M3 M4 --outcomes DV1 DV2 DV3 --out candidates_draft.csv
```

`--single` 与 `--pairs` 可限定范围。脚本只是结构枚举，生成后需补充真实纳入理由、与研究背景核对，并完成第四步确认。未批准的草案不进入批量估计。

## 简单线性方案

当独立采样、连续/近似连续变量及加性无交互假定适用时，可用：

- 单中介：`M = α + aX + γC + εM`；`Y = β + c′X + bM + δC + εY`。
- 双中介并行：各 M 分别对 X 与相同 C 回归，Y 同时纳入两个 M；特定间接效应为各 `a_j b_j`，总间接效应为其和。
- 使用同一分析样本及一致 C 的线性模型时核对 `c = c′ + Σab`。这只检验计算一致性，不证明因果识别；稳健损失、非线性链接或不同样本不能强制满足该恒等式。

X 的对比方向、变量单位、标准化分母和缺失策略必须明确。构念按题均值还是总分会影响路径系数的单位；报告间接效应的原单位。若用 `ab / SD(Y)`，明确 SD(Y) 取哪个分析样本，且 bootstrap 的分母是否在每次重抽样中重新计算。

HC3 可处理独立观测下的异方差标准误，不能修复聚类、反向关系或遗漏混杂。重复测量、聚类、多处理组、有交互、潜变量或非线性结果应另拟方案，并在第四步说明估计量及识别条件。没有相应估计实现时说明限制，不把 logit 系数乘积包装为原量尺间接效应。

## 区间与多重比较

- 可将主分析 5,000 次、敏感性 2,000 次 bootstrap 作为资源允许时的起点，第四步确定具体配置并记录种子。次数并非效度保证，必要时评估 Monte Carlo 稳定性。
- 以独立采样单位联合抽样，保留同一记录的 X/M/Y/协变量关系。独立随机两组设计可在处理组内分层；聚类设计按独立群组抽样，不能对行号简单重抽样。
- 明确 percentile、BCa、模型区间或其他方法。说明逐项覆盖、同时覆盖和模型选择后的不确定性不同。记录失败/不收敛重抽样，不静默删掉直到显著。
- 模型搜索要定义检验族：例如主要 DV 的处理效应、处理中介差异、全部特定间接路径分别管理。不能报告原始 p 却称已校正。
- 对简单线性乘积的“a=0 或 b=0”复合零假设，可使用有效组件检验构成的交并检验 `p=max(p_a,p_b)`，再按已确认检验族做 Holm 等校正。它依赖组件推断有效且较保守，不能称为 bootstrap p。
- 总间接效应的描述性区间不自动成为另一组额外“发现”。不从 bootstrap 正负比例随意构造未经论证的双侧检验，也不在检验方案之间挑最显著者。

## 比较和诊断

保留所有已尝试结构：n、单位/变量、估计法、总效应/直接效应/总与特定间接效应、原始与校正 p、区间类型、样本规则、收敛和诊断。原 p 不可得时写明，不编造。

R²、调整 R²、结果方程 AIC/BIC 可在同一 DV、同样本、可比似然下辅助比较。Y 回归 BIC 不是完整中介 SEM 的整体适配度，也不是机制为真的概率。双模型相对相应较佳单模型的新增 R²仅是样本内描述；不能将更大的 R²直接判为因果解释更好。

检查设计矩阵秩、共线性、残差关系、异方差、极端/影响个案、结果范围与模型类型。诊断显著与否不是自动切换模型或删除样本的规则。对双模型分别检查两个特定路径，说明是否只是已知强中介“带着”另一个无贡献变量。

## 第六步的合理规格

根据已确认方案选择有理由的规格，不强制每个项目都做固定六种：

| 改变 | 要回答的问题 | 解释限制 |
| --- | --- | --- |
| 合理替代计分或有效题阈值 | 结论是否依赖单一操作化 | 改变了测量定义；不能用最显著计分反过来选量表 |
| 既定质量/速度规则 | 哪些记录影响模式 | 排除后的目标样本不同；阈值需有依据 |
| 原值与合理缩尾/稳健估计 | 结果是否由极端值驱动 | 保留主分析原值；估计目标可能改变 |
| 有理论依据的处理前协变量 | 结论是否依赖特定调整集 | 协变量不能按 p 筛选，也不随意控制处理后变量 |
| 留一法或影响分析 | 是否由少数个案支配 | 不能作为独立复现 |
| 与结果量尺匹配的链接 | 线性近似是否影响方向/解释 | 非线性系数尺度不同，不直接比较数值或乘积 |
| 重抽样选择频率或验证样本 | 候选排名有多稳定 | 样本内选择频率不是复现概率；预测稳定也不验证中介因果机制 |

输出所有规格的效应、区间、n、方向变化、路径贡献、是否改变估计目标和失败记录。方向一致但所有区间跨0不叫“稳定显著”；不要把依赖同一数据的规格计作多次独立支持。

## 第七步机制审查

逐候选记录理论契合、构念区分、时序、M-Y 混杂、处理中介交互假定、共同方法、竞争机制、文字支持/反例以及下一步可证伪检验。随机处理并不随机化中介；没有正式未测混杂敏感性分析时明确其缺口。实验因果识别与统计模型适配度分开评估。
